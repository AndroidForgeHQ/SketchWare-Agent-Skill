# SketchWare Agent Skill

## Build Android applications with SketchWare using AI Agents.

SketchWare Agent Skill is an open-source project designed to help AI coding agents understand, design, generate, and manage SketchWare projects through a modular development workflow.

The goal is to make Android app development with SketchWare more accessible by allowing developers to describe what they want in natural language and use AI agents to assist with project creation, UI design, logic blocks, components, events, libraries, and resources.

## ✨ Project Goals

- Generate SketchWare-compatible Android projects.
- Design application interfaces and layouts.
- Create and manage logic blocks.
- Configure application components and events.
- Manage external libraries and dependencies.
- Organize images, icons, and other project resources.
- Simplify repetitive SketchWare development tasks.
- Enable AI-assisted visual Android application development.

## 🧩 Project Architecture

The project is organized into independent modules, each responsible for a specific part of the SketchWare development workflow.

Module| Responsibility
"sketchware-project-generator"| Project creation and configuration
"sketchware-layout-designer"| UI layout and interface design
"sketchware-components-manager"| Component management
"sketchware-blocks-engine"| Logic block generation and management
"sketchware-events-manager"| Event configuration and handling
"sketchware-library-manager"| External library management
"sketchware-resources-manager"| Images, icons, and project resources

## 🚀 Planned Workflow

The intended development workflow is:

1. Describe your Android application to an AI agent.
2. The agent interprets your requirements.
3. The project generator prepares the project structure.
4. The layout designer handles the application interface.
5. The blocks engine manages application logic.
6. Components and events are configured.
7. Libraries and resources are organized.
8. The generated project is validated and prepared for use with SketchWare.
